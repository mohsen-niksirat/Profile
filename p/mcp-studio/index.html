MCP Studio

The visual IDE & testing studio for Model Context Protocol servers.
محیط گرافیکی تست، بازرسی ابزارها و اشکال‌زدایی سرورهای MCP

Visual IDE and testing workbench for Model Context Protocol (MCP) servers — connect to endpoints, browse exposed tools, resources, and prompt schemas, inspect raw JSON-RPC traffic, and invoke tool calls interactively from a clean studio UI.

استودیوی بصری و محیط تست برای سرورهای استاندارد Model Context Protocol (MCP)؛ امکان اتصال به سرور، بررسی اسکیمای ابزارها و منابع، مشاهده ترافیک JSON-RPC و اجرای تعاملی توابع بدون نیاز به نوشتن اسکریپت تست.
