9router AI Gateway

Multi-provider AI gateway, key pool & Telegram Mini App.
درگاه چندسرویس‌دهنده هوش مصنوعی، توزیع بار کلیدها و مینی‌اپ تلگرام

Universal Multi-Provider AI Gateway & Telegram Mini App that routes, load-balances (Round-Robin, Smart Router, automatic 429 failover), and pools API keys across Gemini, Groq, DeepSeek, OpenAI, and OpenRouter — complete with per-user AES key encryption and multimodal vision support.

درگاه یکپارچه هوش مصنوعی و مینی‌اپ تلگرام که درخواست‌ها و کلیدهای API را بین Gemini، Groq، DeepSeek، OpenAI و OpenRouter با الگوریتم‌های Round-Robin، مسیریاب هوشمند و جایگزینی خودکار هنگام خطای Rate-Limit توزیع می‌کند؛ همراه رمزنگاری اختصاصی کلیدهای هر کاربر و پردازش تصویر.

9router automatically marks the exhausted key on cooldown and transparently retries the request against the next healthy key or fallback provider in milliseconds.

9router به‌صورت خودکار کلید محدودشده را موقتاً کنار می‌گذارد و درخواست را بدون وقفه روی کلید یا سرویس‌دهنده جایگزین اجرا می‌کند.
