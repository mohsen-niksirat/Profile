Repodest

Understand any GitHub repository in seconds & pack it for LLMs.
تحلیل فوری هر مخزن گیت‌هاب و ساخت پرامپت آماده برای هوش مصنوعی

Client-side GitHub repository analyzer and LLM-ready digest generator. Paste any GitHub URL to get a 0–100 health score, language breakdown, interactive file explorer, commit insights, and fun trophies — then pack selected files into a prompt ready for ChatGPT, Claude, or Gemini.

تحلیلگر کاملاً سمت کاربر برای مخزن‌های گیت‌هاب و سازنده خلاصه آماده برای مدل‌های زبانی. لینک هر ریپو را وارد کنید تا امتیاز سلامت، نمودار زبان‌ها، مرورگر فایل، آمار کامیت‌ها و تروفی‌ها را ببینید و فایل‌های دلخواه را در قالب پرامپت آماده کپی کنید.

Frequently askedپرسش‌های پرتکرار

Does Repodest send repository code to a backend server?آیا Repodest کدهای مخزن را به سرور واسط می‌فرستد؟

No. Repodest runs 100% in your browser and talks directly to the public GitHub API. Selected files are assembled locally on your machine before you copy them into your LLM of choice.

خیر. Repodest کاملاً در مرورگر شما اجرا می‌شود و مستقیماً با API عمومی گیت‌هاب ارتباط می‌گیرد؛ بسته‌بندی پرامپت هم روی دستگاه خودتان انجام می‌شود.

Is there a browser extension version?آیا نسخه افزونه مرورگر هم دارد؟

Yes — Repodest-Extension adds a floating action button directly on github.com repository pages so you can inspect health metrics and pack files without leaving the repo.

بله، افزونه Repodest-Extension مستقیماً روی صفحات گیت‌هاب باز می‌شود تا بدون خروج از صفحه، خلاصه مخزن را ببینید.
